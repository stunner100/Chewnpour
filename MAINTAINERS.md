# Maintainers

## Primary maintainer

**Patrick Annor** — GitHub [@stunner100](https://github.com/stunner100)

Patrick is the primary maintainer for Chewnpour. This repository does not currently document a separate organization, team, or delegated maintainer group.

## Responsibilities

The primary maintainer is responsible for:

- Maintaining the system architecture and the boundaries between stitch-app, docling-service, and study-agent.
- Triaging issues and deciding whether proposals fit the project scope.
- Reviewing pull requests for correctness, security, maintainability, and documentation quality.
- Reviewing QA evidence and deciding when provider-dependent checks are sufficient.
- Coordinating private security reports and disclosure decisions.
- Preparing releases, migrations, release notes, and rollback plans.

Contributors are encouraged to make focused changes and explain operational impact. Maintainer responsibilities may be delegated in the future, but no such delegation is recorded here.

## Contact

Use GitHub issues for ordinary project questions and proposals. Use the private reporting path in [SECURITY.md](SECURITY.md) for vulnerabilities.
